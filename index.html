Ecommerce Store

This is a production ecommerce store I built for a YouTube channel with 40,000 subscribers. It features a SPA on the frontend that takes the customer through the storefront and checkout process. The frontend also includes an admin page that allows the client to update their storefront information dynamically. I integrated Stripe for payment processing and Shippo for shipping. The backend functions as a REST API built with NodeJS and Express, and uses JWT for security on the admin page. Images are stored in object storage via AWS S3 and Postgres is used for the database. The entire app is deployed in the cloud via Render. The store is live and actively serving customers, processing real payments and shipping orders.

MLB Web App

This is a Major League Baseball (MLB) website built with React. The website features real-time updates to show the latest stats, rosters, and in-game data. It also includes graphics to show the current state of each game such as the score, inning, outs, and runners on base. The app consumes live MLB API data and uses React's component model and state management to keep the UI in sync with real-time game events.
